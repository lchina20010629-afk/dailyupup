# 今天里提问

日期：2026-11-18

## 意图

记录生活要快。同一个人也会在白天随口问一句，并自己决定这句回答要不要收进当晚的日记。提问和记录在同一条对话里完成，不另开一页。

## 目标

- 「今天」的输入框左边有「记」和「问」。打开页面时停在「记」。
- 「记」沿用现在的发送：右边气泡，文字、语音、照片、视频、表情都在。发出去就属于当晚日记。
- 「问」只发文字。问题在右边，回答在左边。回答下面有「记进日记」。
- 点「记进日记」后，问题和回答一起成为当晚日记的一条原文。按钮变成「已记」。没点的回答只留在今天的对话里，夜里的整理看不到它。
- 刷新后，没记进日记的问答还在。发出、回答、记下都不整页刷新。

## 非目标

- 看见问号就自动回答。
- 给提问配照片或视频。
- 把回答再润色成另一篇文章。夜里的整理只是把已记下的问答和其他原文收在一起。
- 换一个模型，或另做一个提问页。

## 反目标

- 随口记下的「今天午饭好吃吗」被当成提问。
- 没点「记进日记」的回答出现在日记里。
- 记进日记之后，对话里又多出一条重复的右边气泡。

## 约束

- 界面中文。一天按 `Asia/Shanghai`。
- 模型只用服务器上的 DeepSeek `deepseek-chat`。回答用中文，短一些，不编造对方没问的生活事件，不写成日记。
- 提问接口要登录，和记录接口一样。整理完成之后不能再把回答记进日记，也不能删，返回 409。
- 顶栏仍是今天、日记、学习。输入栏留在底部。

## 做法

采用输入框旁的「记 / 问」。带问号的生活记录不会去问模型。

问答存在新表 `asks`。点「记进日记」时再写一条普通记录，正文是：

```
问：……
答：……
```

夜里的整理继续只读记录表。对话渲染时，已经挂上这条记录的提问不再单独显示成右边气泡。

没选的做法：问号自动回答。少一次拨动，但会把自言自语送去模型。
